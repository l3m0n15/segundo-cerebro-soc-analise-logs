# Segundo Cérebro: Análise de Logs em SOC

## 1. Objetivo do projeto

Este projeto tem como objetivo criar um segundo cérebro utilizando o Gemini Notebook para estudar Análise de Logs em SOC (Security Operations Center), com foco em monitoramento, detecção e investigação de incidentes de segurança.

A proposta é organizar fontes confiáveis de estudo, utilizar inteligência artificial para aprofundar o conhecimento e gerar materiais que facilitem a aprendizagem.

## 2. Tema escolhido

**Análise de Logs em SOC: Monitoramento, Detecção e Investigação de Incidentes**

O foco é compreender como os logs ajudam profissionais de segurança a identificar atividades suspeitas, investigar alertas e reconhecer possíveis incidentes.
